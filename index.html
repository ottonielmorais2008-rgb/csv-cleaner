CSV Cleaner

Open a CSV, review empty cells, duplicate rows, type mismatches and inconsistent date formats, then apply fixes and download a cleaned file. The data never leaves this tab: there is no server, and a strict Content Security Policy sets connect-src 'none' so the page cannot make network requests.

Load a CSV file

What this tool does

  • Runs entirely in your browser. The CSV is never uploaded or sent over the network.
  • Detects empty cells, leading or trailing whitespace, duplicate rows, values that do not match an inferred column type, and simple inconsistent date formats.
  • Can trim whitespace, remove duplicate rows, drop or fill empty cells, and normalize numbers (thousands separators and decimal marks).
  • Date checks cover common formats such as YYYY-MM-DD, DD/MM/YYYY, DD-MM-YYYY and DD.MM.YYYY. Ambiguous day/month order is not rewritten.

Open source on GitHub. The file you choose is not uploaded.
